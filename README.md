# Тепло

Дневник благодарности с питомцем, который растёт от твоих записей.

Пишешь, за что благодарен — питомец получает ингредиент для коктейля,
растёт и обживает полянку. Без streak'ов, без «ты пропустил день»,
без списков незаработанного.

## Попробовать

Открой ссылку на GitHub Pages — приложение работает прямо в браузере,
удобнее всего с телефона.

Ничего устанавливать не нужно и регистрации нет. Все записи хранятся
**только в твоём браузере** (`localStorage`) и никуда не отправляются —
сервера у приложения нет вообще.

Чтобы оно жило иконкой, а не вкладкой: в меню браузера выбери
«Добавить на главный экран».

Записи можно сохранить себе — кнопки в панели вещей (значок корзинки).
Это стоит сделать: если почистить данные браузера, записи пропадут.

## Что интересно услышать

- Понятно ли с первого экрана, что вообще происходит?
- Вопросы для записей — попадают или звучат натужно?
- Хочется ли вернуться на следующий день? Что бы этому помогло?
- Что-нибудь вызвало неловкость или чувство, что тебя подгоняют?

## Локально

Открыть `index.html` напрямую или поднять сервер:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1
```

Чистый HTML/CSS/JS, без сборки и зависимостей.
Архитектура и принципы — в [CLAUDE.md](CLAUDE.md).
